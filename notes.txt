Node JS Architecture:
client make request to server
request first queue in event queue
if user 1 req -> event queue
user 2  -> event queue 
after that req goes to event loop 
FIFO 
pick req it is of two types:
Blocking operations (SYNC)
Non - Blocking operations (ASYNC)

if it is Non-Blocking:
it is simple req then it process and response to the user.

if it is Blocking Operation:
then it goes to thread pool.
thread pool is a pool in which there are thread.
thread means workers (threads are limited)
then each thread assigning to do task

if no thread free then task will wait until thread become free. 
so always run non-blocking operations. [Async]

Default thread pool size = 4 {max req = 4}
increase up to your cores in cpu .
